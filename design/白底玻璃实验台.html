病理:浅色模式的整套「形」由白色系 token 承担——glassBorder 白.30、puck 白.62、thumbBorder 白.35、玻璃本体近透明。 白底上它们全部同色隐形,面板退化成「浮着的图标 + 一团阴影」。深底好看,正因为白 token 在深底上显形。
修法只有两路:救玻璃(浅灰骨 tint)/ 救形(灰色族边与托底)。对照如下,四个方案只改浅色族,深色一律不动。

判词与落地映射

白底「反光」是双重事故:玻璃隐形(透明材质叠无内容背景)+ 形隐形(白色系 token 叠白纸)。 V1 只救玻璃——有形了但托底还是消失;V2 只救形——轮廓和托底回来了,但面板本体仍是一团空气; V3 才两病都治。
原生映射(只动浅色族,深色一行不改):
· V1 = PanelGlass.scrim 浅色也吃一片浅灰滤光片 rgba(235,238,243,~.5)(与深色 scrim 同法,官方 tintColor,不手刻材质);
· V2 = PanelColors 浅色值换族:glassBorder 白.30→黑.10、puck 白.62→黑.10、thumbBorder 白.35→黑.10;
· 浅彩/深底不劣化:浅灰骨在彩色背景上仍透色(Dock 在白桌面上读作浅灰,同一物理)。
· HTML 的 backdrop-filter 与 NSGlassEffectView 光学不完全一致,方向可信,绝对数值落地后实机微调。
