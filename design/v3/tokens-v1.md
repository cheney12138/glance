# Glance 面板 · Token 契约 v1(治 v0.2 四病)

> 本表是视觉工艺层的施工契约;交互语义与结构仍以 `design/brand-spec.md`(v0.2 冻结)为准。
> 图纸:`design/v3/Glance 面板原型 v1.html`(自包含,素材全内嵌;`template.html` + `build.py` 可重新生成)
> 验收口径:与 DockDoor 实物并排不糙一档;200% 放大后选中态/阴影/图标边缘经得起看。

## 四病 → 处方(一句话对照)

| v0.2 的病 | v1 的处方 |
|---|---|
| 图标像贴在玻璃上的贴纸 | 图标不裁圆角、直接渲染真实 squircle alpha;阴影用 `drop-shadow` 跟轮廓走,不用 `box-shadow` 贴方块 |
| 预览卡像数据表格 | 卡面 = 标题栏带 + 截图,无文字标题;层次靠"窗口自己的两个原生线索"(标题栏 + 红绿灯),不发明新的 |
| App 名喧宾夺主(v1 评审) | **名字从长条删除**(推翻 v0.2"名字置顶"冻结项,评审拍板):名字的职责被预览窗标题取代,长条只剩图标;辨识需求由窗口名承担 |
| 红绿灯压在内容上发乱(v1 评审) | 根因是素材截图被裁掉了标题栏,灯悬空。把 26px 磨砂标题栏带还给窗口,灯住进带内垂直居中;窗口名同排居中 |
| 毛玻璃灰脏 | 降不透明度(浅 .55→.46 / 深 .60→.55)、提饱和度 1.3→1.9、顶部加 0.5px 受光边——脏来自"灰色不透明",不是来自模糊 |
| 选中态只有色块套娃 | 选中 = 层级变化:图标轻微上浮 + 阴影加深 + 极轻托底;卡片用 knockout + 系统聚焦环,不再叠白块 |

## 1. 颜色(浅 / 深双值)

| Token | 浅色 | 深色 | 为什么 |
|---|---|---|---|
| `--accent`(唯一彩色) | `#007AFF` | `#0A84FF` | 系统聚焦环本色;深色用提亮版是 Apple 自己的做法(Dark Mode 下蓝统一提亮) |
| 红绿灯 | `#FF5F57` / `#FEBC2E` / `#28C840` | 同左 | 冻结项;深浅不变,因为它们本来就是"玻璃上的实物" |
| `--label-name`(窗口名) | `rgba(0,0,0,.60)` | `rgba(255,255,255,.62)` | 窗口名是标注不是标题:比系统 label 淡一档,辨识够用、存在感让位给截图 |
| `--label-2nd`(辅助) | `rgba(0,0,0,.45)` | `rgba(255,255,255,.45)` | 仅演示页用,产品面板内无次要文字 |
| 标题栏带 `--tb-tint` | `rgba(246,247,248,.5)` | `rgba(38,39,44,.5)` | 模拟真实窗口标题栏:半透明磨砂(带内 blur 18),截图什么色它就随什么色,灯永远有"家" |
| 标题栏下发丝 `--tb-line` | `rgba(0,0,0,.06)` | `rgba(255,255,255,.08)` | 真实窗口标题栏与内容之间本就有这条线;它不是装饰,是"窗口"的物证 |
| 玻璃 tint | `rgba(248,249,251,.46)` | `rgba(30,31,36,.55)` | 浅色接近白但不到白:留给背后世界透进来的余地;深色压到 #1E1F24 附近,比纯黑暖半度,避免"沥青板" |
| 玻璃受光边 `--edge-hi` | `rgba(255,255,255,.55)` | `rgba(255,255,255,.13)` | 顶部 0.5px 内高光——浮层"厚度"的全部来源,比任何外阴影都诚实 |
| 玻璃轮廓 `--edge-ring` | `rgba(0,0,0,.08)` | `rgba(255,255,255,.10)` | 0.5px 外缘:浅色用深边、深色用亮边,永远与背景拉开,不追求"看得见",追求"没它就不对" |
| 选中托底 `--plate` | `rgba(0,0,0,.055)` | `rgba(255,255,255,.09)` | 原生 ⌘Tab 选中块的实测量级:刚好可见,绝不宣兵夺主 |
| 聚焦环 knockout `--ko` | `rgba(252,252,253,.95)` | `rgba(24,25,29,.95)` | 把蓝环从截图内容上剥开的一道"底色缝",近似玻璃面的颜色;没有它,蓝环直接压在花花绿绿的截图上会脏 |
| 未选卡发丝 `--card-ring` | `rgba(0,0,0,.10)` | `rgba(255,255,255,.13)` | 截图四边需要一根 0.5px 的"纸边",否则亮截图在亮玻璃上会化开 |

## 2. 圆角

| Token | 值 | 为什么 |
|---|---|---|
| `--r-panel` | 22px | 面板大到能"看见圆角的弧度",20 略紧、24 开始蠢;22 与 76px 图标的 squircle 曲率视觉同族 |
| `--r-cell` | 19px | 比面板小 3px:同心圆角原则,托底在面板内,弧度差 = 两者间距的视觉补偿 |
| `--r-card` | 10px | macOS 窗口圆角实测值;截图是"窗口",必须用窗口的圆角,不能用面板的 |
| 红绿灯 | 50%(10px 圆) | 冻结项 |

## 3. 阴影(偏移 / 模糊 / 透明度)

| Token | 值(浅 / 深) | 为什么 |
|---|---|---|
| 长条 `--shadow-strip` | `0 24px 70px / .20` + `0 4px 16px / .09`;深色 `.55` / `.34` | 双层:远层给"浮",近层给"锚"。单层大阴影会糊成雾,双层才有高度读数 |
| 浮窗 `--shadow-pop` | `0 30px 84px / .24` + `0 6px 18px / .10`;深色 `.60` / `.38` | 浮窗在长条**上方**,阴影必须比长条更高一档——阴影高度 = 视觉高度,这是两个容器唯一的层级语言 |
| 图标 `--icon-shadow` | `0 5px 12px / .20` + `0 1px 2px / .14`(drop-shadow);深色 `.30` / `.22` | drop-shadow 跟图标 alpha 轮廓走,这是"浮空感"的全部秘密;box-shadow 画方块即贴纸 |
| 选中图标 `--icon-shadow-sel` | `0 8px 16px / .24` + `0 1.5px 3px / .16`;深色 `.36` / `.26` | 选中 = 升高 3px 的等价物:y +3、模糊 +4、透明度 +.04,配合 `translateY(-1px)` |
| 卡片 `--card-shadow` | `0 10px 24px / .14` + `0 2px 6px / .10`;深色 `.42` / `.30` | 卡片在浮窗内,高度必须低于浮窗本身——层次:浮窗 > 卡片 > 截图 |
| 选中卡 `--card-shadow-sel` | `0 14px 32px / .20` + `0 3px 8px / .12`;深色 `.50` / `.34` | 选中卡微微"离席":阴影升一档,与聚焦环同时发生,手和眼睛收到同一个信号 |

## 4. 间距与尺寸

| Token | 值 | 为什么 |
|---|---|---|
| 图标 `--icon` | 76×76 | 主角就要有主角的体格:名字让出来的视觉重量全部给图标;384px 源图保证 200% 检视不糊 |
| 图标格 `--cell` | 88×88 | 图标外留 6px:托底紧贴图标,选中块"认领"图标而不是框住一片空气(v1 评审后收紧) |
| 格距 `--cell-gap` | 8px | 相邻图标边到边 = 20px,与原生 ⌘Tab 视觉密度一致(实测原生约 18–22px) |
| 长条内边距 | 12 / 14(四向) | 名字删除后上下对称:容器"刚合包住图标行",不留展厅(v1 评审拍板) |
| 标题栏带 `--tb-h` | 26px | 接近 macOS 标准标题栏 28px 的缩略比例;红绿灯(10px)在带内垂直居中,左右留白 10px |
| 截图区 `--card-h` | 190px(卡总高 216) | 高度统一、宽度随窗口原始比例:等高等比 = Mission Control 群像感;等宽裁切 = 表格感(v0.2 的病) |
| 卡距 `--card-gap` | 12px | 小于浮窗内边距的 1.5 倍会散,大于它会粘;12 让相邻截图的阴影刚好不叠加 |
| 浮窗内边距 `--pop-pad` | 12px | 与卡距相同:卡与卡、卡与边同距,浮窗内只有一阶节奏 |
| 浮窗 ↔ 长条 `--pop-gap-y` | 16px | 两个独立容器的"空气缝":太小读成嵌套(v0.1 的病),太大读成无关 |

## 5. 字体

| 语义 | 值 | 为什么 |
|---|---|---|
| 窗口名 | 11px / 500 / SF Pro Text,色 `--label-name`;标题栏带内全宽居中,`max-width: calc(100% - 96px)`,超长 `…` 省略 | 同 App 多窗的唯一文字区分;11px 是 26px 带内的原生比例(真实窗口 13px @ 28px 带的缩放换算);省略用宽度截断而非数字数,中英文混排都稳 |
| 红绿灯 | 10px 圆点、间距 8px,标题栏带内垂直居中、左缘 10px | 冻结项(灯本身);位置从"压截图"改为"住进标题栏带"——v1 评审后修订,灯不再与窗口内容撞色 |

## 6. 动效(全部无回弹)

| 动作 | 时长 | 曲线 | 为什么 |
|---|---|---|---|
| 面板弹出 | 120ms | `cubic-bezier(.2,.8,.2,1)`,scale .96→1 + 透明 | 冻结值;scale 从 .96 而不是更小:这是"出现",不是"蹦出来" |
| 浮窗出现 | 120ms | `cubic-bezier(.2,.8,.2,1)`,translateY -5→0 + 透明 | 比冻结值(80ms)多 40ms:80ms 肉眼读不到方向 |
| 卡片错落入场 | 每张 160ms,相邻延迟 18ms | `cubic-bezier(.2,.8,.2,1)`,translateY -6→0 + scale .97→1 + 透明 | 群像要"铺开"不要"砸下来";18ms 是刚好可感知节奏的最小步,再大就像排队买票 |
| 浮窗换组(换 App) | 本体不动,仅卡片重排入场(同上) | — | 浮窗横滑已经给了"换了人"的信息,本体再闪一次就是重复播报 |
| 浮窗滑移(换 App) | 180ms | `cubic-bezier(.25,.8,.3,1)`,只动 `left` | 唯一允许超过 150ms 的动作:位移距离长,180ms 保证"滑过去"而非"闪过去";无回弹,弹簧物理在此是炫技 |
| 选中态切换 | 100ms | ease,托底/环/阴影同步 | 冻结值;三个属性同时动,否则眼睛会收到两拍 |
| `prefers-reduced-motion` | 全部 → 0 | — | 冻结项,原型已内置 |

## 7. HTML → 原生翻译(给 SwiftUI)

| HTML | 原生 |
|---|---|
| `backdrop-filter: blur(30px) saturate(1.9)` + tint | `NSVisualEffectView` material `.popover` state `.active`;**不手写底色**, tint 值仅作验收对照 |
| `drop-shadow` 图标阴影 | 图标 `NSImageView` 关 wantsLayer 阴影,用 `.shadow(radius: 6, y: 3, opacity: .2)` 打在图片层(跟 alpha) |
| knockout + 聚焦环 | `StrokeBorder` 双层:内 2px 面板近似色、外 2.5px `Color.accentColor` |
| 标题栏带 | 26pt 高 `NSVisualEffectView`(material `.titlebar`,state `.active`)+ 底部 0.5pt `separatorColor`;截图从带下缘起绘 |
| 红绿灯三圆点 | 10pt `Circle()` 三色,带内垂直居中、左缘 10pt,间距 8pt;或直接复用系统截图资产 |
| 窗口名 | `Text(title).font(.system(size: 11, weight: .medium)).lineLimit(1).truncationMode(.tail)`,带内居中,`.foregroundStyle(.secondary)` |
