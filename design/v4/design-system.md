## 0. 不变量(Invariants)

以下任何版本迭代**禁止**违反:

1. 双容器、不嵌套;浮窗水平中心**必须**正对选中 App 图标,超界收进语境屏。
2. 全系统彩色仅两源:聚焦蓝 `--accent`、红绿灯三色。**禁止**引入第三种彩色。
3. **禁止**振荡/弹簧物理;**禁止**任何动画超过 240ms。唯一许可的欠阻尼:选中卡浮起(单次 settle,overshoot ≤1.35,无二次振荡,v1.1 评审拍板)。240ms 上限管关键帧动画与状态过渡;材质光(高光质心、色散)的连续跟随与演示布景不受此限(v1.4 修订)。
4. 图标**必须**以原始 squircle alpha 渲染,**禁止** CSS 裁形;图标阴影**必须**用贴合轮廓的方式(drop-shadow / 图片层阴影),**禁止**矩形 box-shadow。
5. 窗口卡**禁止**出现标题栏带以外的文字、按钮、角标。
6. `prefers-reduced-motion` 下所有动效**必须**归零。

## 1. 度量系统

**一切尺寸是 4 的倍数。** 唯一例外:0.5px 发丝线与红绿灯(10px,系统规格)。

### 间距阶梯

| 阶梯 | 值 | 用途 |
|---|---|---|
| s1 | 4 | 微调,仅用于图标选中上浮等亚阶梯补偿 |
| s2 | 8 | 图标格间距、红绿灯间距 |
| s3 | 12 | 标题栏左缘等局部留白 |
| s4 | 16 | 长条/浮窗内边距、卡间距、浮窗↔长条间距 |
| s5+ | 24/32 | 页面级留白,面板内不出现 |

规则:同层元素间距**必须**取自同一阶梯值(卡与卡、卡与边同为 s4——一个容器内只允许一阶节奏)。

### 圆角阶梯(同心规则:外角 = 内角 + 间距,取整到阶梯)

| 阶梯 | 值 | 用途 |
|---|---|---|
| r2 | 10 | 窗口卡(= macOS 窗口圆角实测) |
| r3 | 14 | 选中托底 |
| r4 | 24 | 两个面板容器(≈ 卡 r10 + 内边距 s4,同心规则) |
| — | 50% | 红绿灯 |

### 2.2 液态玻璃(v1.10,单配方,两容器共用)

材质 = **透(tint)+ 磨砂(blur/saturate/brightness)+ 发丝轮廓(edge-ring)+ 失重影(2.3)+ 唯一的指针游光**。v1.10 裁决:rim 折光环、色散边、边缘透镜带三层 HTML 逼近**全部废除**(两轮评审连坐:亮框→内角;HTML 叠层逼近不了 NSGlassEffectView 的边缘折射,不做胜过做错——该职责归原生实现,见 §5)。

| 参数 | 浅色 | 深色 | 约束与理由 |
|---|---|---|---|
| tint | `rgba(252,252,254,.26)` | `rgba(28,32,42,.34)` | 灵魂是"看得见背后",不是"盖得住背后";上限 .45,超过即回磨砂板。v1.5 再降(浅 .33→.26 / 深 .42→.34):评审要求"大胆高透",面板形改由 rim + edge-ring + E 级收束,不靠 tint 盖 |
| ~~sheen~~ | 已删除(v1.8) | 已删除 | v1.0–v1.7 为 180° 顶光;与静态光泽叠层后成"磨砂盖",废除 |
| blur / saturate / brightness | 44px / 2.0 / 1.04 | 同左 / 1.02 | blur ≥36 才有水晶感;v1.4 40→44,把布景硬边再柔一档 |
| ~~折光环 `--rim`~~ | 已废除(v1.10) | 已废除 | 静态亮弧在边缘 = 边框,不是材质 |
| ~~色散边 `--fringe`~~ | 已废除(v1.10) | 已废除 | 同上;不变量 2 的色散豁免随层下线 |
| ~~静态光泽 `--spec-static`~~ | 已删除(v1.8) | 已删除 | v1.4 引入的"无人也活";v1.8 反向裁决:静置均匀大于静置发光,指针游光已是唯一的光 |
| 游动高光 | 径向 300×200,白,α `.24`,跟指针,离场 0.5s 归位 (50%, **−60%**,推出板外,v1.9) | α `.12` | 光是材质的一部分,不绑任何选中/hover 状态;`@property` 注册 `--sx/--sy` 使质心位置可过渡;停泊位在板外,静置顶缘不吃游光溢出 |
| 外轮廓 `--edge-ring` | 0.5px `rgba(0,0,0,.09)` | 0.5px `rgba(255,255,255,.09)` | rim 管"光",ring 管"形";v1.4 浅色 .07→.09:高透玻璃上,形线加半档才收得住 |
| ~~边缘透镜带 `.lens`~~ | 已废除(v1.10) | 已废除 | v1.9 撤光后残边仍在,评审拍板去掉:边缘折射归原生 `NSGlassEffectView`,HTML 不逼近 |

约束:原生施工以系统 Liquid Glass 材质为准(macOS 26+ `NSGlassEffectView`,边缘折射/透镜系统自带,**禁止**手刻);HTML 端只做 tint+blur+发丝+阴影+游光。高光半径为光学参数,**不计入** §1 的 4px 布局网格。

### 2.3 Elevation(阴影 = key 塑形层 + fill 锚定层)

层级即语义:**E3 浮窗 > E2 长条 > E1 卡片**。液态玻璃 = 失重:v1.3 起 α 整体下调、blur 加大。深色模式 α **必须** ×1.9(四舍五入;v1.2 及以前为 ×2.2)。

| 级 | 用途 | key(y / blur / α) | fill(y / blur / α) |
|---|---|---|---|
| E1 | 窗口卡静止 | 5 / 14 / .08 | 1 / 3 / .06 |
| E1-hover | 窗口卡悬停 | 7 / 18 / .10 | 1 / 4 / .07 |
| E1-sel | 窗口卡选中(静置) | 9 / 24 / .12 | 2 / 6 / .08 |
| E1-lift | 窗口卡选中(浮起,v1.1) | 13 / 32 / .15 | 3 / 8 / .10 |
| E2 | 图标长条 | 22 / 60 / .15 | 3 / 10 / .06 |
| E3 | 预览浮窗 | 30 / 80 / .19 | 5 / 14 / .08 |
| icon | 图标(贴合轮廓) | drop 4 / 10 / .15 | drop 1 / 2 / .10 |
| icon-sel | 选中图标 | drop 7 / 14 / .19 | drop 1.5 / 3 / .12 |

约束:**禁止**单层大阴影(糊成雾);**禁止**相邻层级交换(浮窗阴影弱于长条 = 层级反转)。

### 2.5 动效

| 动作 | 时长 | 曲线 | 位移 |
|---|---|---|---|
| 面板弹出 | **无(瞬现)** | — | —(v1.12 下线,见 Changelog) |
| 浮窗出现 | **无(瞬现)** | — | —(v1.12 下线) |
| 卡片入场 | 160ms/张,相邻延迟 18ms | 同上 | translateY -6→0 + scale .97→1 + 透明 |
| 浮窗换组 | 本体静止,仅卡片重排 | — | 横滑已传达"换组",本体再动是重复播报 |

| 选中卡浮起(v1.1) | 220ms | `cubic-bezier(.34,1.35,.4,1)`(单次 settle) | translateY 0→-6px + scale 1→1.015,阴影→E1-lift;落选原路返回 |
| 状态切换 | 100ms | ease | 托底/环/阴影三属性**必须**同步 |
| 游动高光(v1.3) | 500ms | ease | 高光质心跟指针,离场归位(50%,-30%);注册 `@property` 使位置可过渡;不绑任何选中/hover 状态 |

### 3.3 WindowCard(窗口卡,E1,r10)

```
┌ r10 ──────────────────────────┐
│ ● ● ● s2 <title 11/500 左对齐…>│ ← tbar 24px:近实哑光带,左右缘 s3,灯距 s2
├─ 0.5px --tb-line ─────────────┤
```

- 选中:`box-shadow` 双环 = 2px `--ko` + 2px `--accent`(v1.1 减环,蓝环与图之间留缝),同时阴影 E1→E1-lift、卡片浮起、标题 --txt-2→--txt-1(见动效表)。

## 5. 原生实现映射(SwiftUI / AppKit)

| Token | 原生 |
|---|---|
| 玻璃 | macOS 26+ 用 `NSGlassEffectView`(液态玻璃);低版本回退 `NSVisualEffectView` `.popover`/`.active`;不手写底色 |
| 折光环/色散边/透镜带 | `NSGlassEffectView` 自带,**禁止**手刻;低版本回退放弃;HTML 原型不再逼近(v1.10) |
| Dock 磁吸放大 | 原型演示特性;原生默认**关闭**,是否挂设置开关另行评审——它不是选中语义的一部分 |
| E2/E3 | 两层 `NSShadow` 叠加或 `.shadow()` 两次;α 按深色 ×1.9 |
| 选中卡浮起 | `withAnimation(.timingCurve(0.34,1.35,0.4,1, duration: 0.22))`;全系统仅此一处允许欠阻尼,**禁止**换成 spring |
| icon 阴影 | 阴影打在 `NSImageView` 图片层(跟 alpha),不打在容器层 |
| 双环选中 | `StrokeBorder` 双层:内 2 `--ko`,外 2 `Color.accentColor` |
| tbar | 24pt 高 `.titlebar` material + 下缘 0.5pt `separatorColor` |
| 窗口标题 | `.system(size:11, weight:.medium)` + `.lineLimit(1).truncationMode(.tail)` + `.foregroundStyle(.secondary)` |
| 动效曲线 | `.timingCurve(0.2,0.8,0.2,1)` / `.timingCurve(0.25,0.8,0.3,1)`,禁止 spring |

### v1.7(评审:高饱布景下标题栏带"为什么这么糊")
- 病因:tbar 的 `backdrop-filter: blur(18px)` 叠在浮窗玻璃上 = 磨砂叠磨砂的双重雾化,高饱布景被搅成脏雾;HTML 端 tbar **摘掉 backdrop-filter**,tint α .50→.62(浅/深同),改读近实哑光带

### v1.8(评审:"深色下磨砂边框盖住了,要整体磨砂通透,不是边框")
- 灭"磨砂盖":删除 sheen 顶光与 `--spec-static` 静态光泽(五要素不变,光的构成收敛 = 指针游光一路 + 1px 发丝 rim);透镜带增亮/饱和 1.07/1.1→1.03/1.04,深色下不再"边框发光"

### v1.9(评审:"还是一样,有明显的内角")
- 真凶到案:内角不是顶光,是**透镜带的亮度差**——brightness/saturate 微增量在平滑布景上把 10px 环带读成一圈内嵌亮框,内边界(半径 14 的圆角矩形)即"内角"。透镜带撤光,只留 `blur(2px)` 纯折射:环带与板心零亮度差,框感消失
- 游光停泊位 (50%, −30%) 推出板外至 (50%, −60%):静置时顶缘不再吃游光椭圆的下缘溢出
- v1.8 的"磨砂盖"与 v1.9 的"内角"同一课:**玻璃面内任何静态亮度差都是边框,不是材质**

### v1.10(评审:"这条边还是有,改不好就直接去掉")

- 不变量 2 的色散豁免随 fringe 下线一并收回

### v1.12(评审:"动效太重了,⌘Tab 的登场淡入淡出给毙掉,不实用、影响效率")
- **入场动效全部下线**:面板与预览托盘一律瞬现(删掉 demo 的 `.switcher-wrap` scale .90→1 与 `.preview-tray` translateY+scale 两段登场)。**退场保留淡出**——那是动作之后的余韵,不在关键路径上;`PanelMotion.rise` 随之删除
- 为什么这次不是审美问题:入场不只是"多花 120ms 看动画",它还占着主线程。事件 tap 的 runloop 挂在主线程上,实测"按键→面板就位"整段会占住主线程 ~110ms,期间系统投递的按键全在排队;超过 tap 超时就会被系统停用,而停用那一瞬漏出去的 ⌘Tab 正好交给 **macOS 原生切换器**(用户实机反馈:"用着用着变成原生那个")。同批修复:
  - 枚举(`WindowEnumerator.rawGroups`)搬后台,让 tap 回调立刻返回(回调内阻塞 ~110ms → ~12ms);MRU 排序仍在主线程(`orderByMRU`)
  - 开启判定改用**事件自带 flags**,不再只信内部 `state == armed`:漏掉一颗 ⌘↓ 的 flagsChanged 也接得住
  - 退场拆迁单带**世代号**:新一轮 begin 之后,迟到的拆迁单既不能拆窗、也不能通知触发层收尾(通知了就把新一局的状态机从 navigating 拉回 idle,后续 ⌘Tab 全漏给系统)
  - 新增 `GLANCE_TRACE=1` 的事件级 trace(输入管线看不见摸不着,这类问题只能靠事件流水账定位)
- **上面这些加固随后被 v1.13 整体替代**:防线不再建在"吞键"上,见下。

### v1.13(评审:"人家 alt-tab 都用那么久的私有 API 了,我们也直接用;靠吞键屏蔽原生按键太重")

**架构级裁决:⌘Tab 的接管从"事件层吞键"搬到"系统快捷键注册表层"**(详见 `docs/adr/0005`)。

- 关掉系统 symbolic hotkey:`CGSSetSymbolicHotKeyEnabled` 关 `⌘⇥`(1)+ 配对关 `⌘⇧⇥`(2),
  `⌘`` 在键位重叠时才关;触发键改由 Carbon `RegisterEventHotKey` 收 —— 系统直接把和弦交给我们,
  前台 App 收不到,**不需要吞**
- tap 收缩成三块:`.listenOnly` 的 flagsChanged(只听修饰键,撑 hold 语义)+ `.listenOnly` 的
  leftMouseDown(⌘+点击补焦)+ **唯一有吞键权的 navTap**(创建即禁用,只在导航态打开,吞 Esc/←→/Q/W/M)
- 赚:v1.12 那一整类"漏一颗 → 原生切换器接管"的失败模式**结构上消失**;tap 的破坏性面只剩会话期那几百毫秒
- 赔:接管的是**系统级**状态且**跨退出持久化** → 恢复责任做全(正常退出 / ObjC 异常 / 四种信号 /
  **启动自愈**);`SIGKILL` 拦不住,那种情况要靠下次启动或 `Tools/NativeHotkeys.swift restore` 手动救
- 实测口径(唯一可信的那种):按住 ⌘Tab 若干秒,看窗口清单里有没有 `程序坞 / layer=20 / 全屏`
  —— 有 = 原生切换器在(热键开着),没有 = 被我们关着。工具见 `docs/debugging.md` 第 7 节
- **默认不许接管**(评审:这个禁用逻辑只能是用户显式开启的):触发键默认 ⌥Tab,一行系统设置都不碰;
  开关 `trigger.takeoverSystemSwitcher` 默认 false,`plan(for:takeover:)` 要求"开关为真 **且** 触发键与
  系统热键重叠"才动手;老版本的遗留状态(键=⌘Tab 但没有开关)启动时归一回 ⌥Tab
- **Carbon 热键不重复投递**:同一个和弦按住期间只来第一发 `kEventHotKeyPressed`
  —— 实机病"⌘Tab 唤起了但继续按 Tab 不动"。修法:Carbon 只管开局,导航期的循环移动交回 navTap

### v1.14(评审:"说白了,像是零几年的 macOS 系统那种玻璃质感太过时了")

**只在深色态动刀** —— 浅色那一格(白 .26 底 / ink .06 边)是用户逐轮调出来的,这轮一格未动。

- **删掉"上缘高光唇 + 亮描边"这一对**:它们是 Aqua 时代"会反光的玻璃胶囊"的签名。
  高光唇(沿胶囊弧走、往下收干的一道白边)整段下线,亮描边从白 .24 压到 **.10**
  —— 只留"这里有一块"的一丝边界,读不出"一根亮线"
- **底的材质语言换了一代**,不是"再淡一点":旧版是"贴在玻璃上的牌子"——它的亮度**不随背景变**
  (实测恒为 L≈45,因为那就是 `slate(44)` 实色自己),而四周玻璃在 L53…218 之间摆动;
  新版是"玻璃上的第二层雾":`slate(22) α .40`,浅底落到 **L≈118**、深底落到 **L≈41**,
  需要它显形的地方(白底玻璃)它显形,本来就暗的地方它自己消失
- **"清透"仍由半透承担,不由受光边承担**:透过芯片看到的是**已经毛玻璃化**的画面 ——
  玻璃叠玻璃该有的样子。这条取代 `芯片=一块有受光唇的玻璃` 的旧说法
- 文字补到白 .92 兜住对比度(底淡了一档)

**可复用的判据**(这一轮的通用收获):**玻璃面上任何"不跟随背景变化"的静态亮度差,
读起来都是贴上去的东西,不是材质。** 上缘高光、亮描边、内嵌亮框,都属于这一类 ——
它们描述的是"光打在这块玻璃上",而用户眼里看到的是"这块东西和它背后没关系"。
