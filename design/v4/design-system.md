# Glance Design System v1.0

> **Status**: Stable / 可施工
> **Supersedes**: design/v3/tokens-v1.md(全部数值)
> **图纸**: `design/v4/Glance 面板.html`(自包含;`template.html` + `build.py` 可再生)
> **交互语义**: 沿用 `design/brand-spec.md` 冻结项,本文不重复;本文只管**视觉与动效工艺**

本文关键词 **必须(MUST) / 禁止(MUST NOT) / 应当(SHOULD)** 按 RFC 2119 语义使用。数值偏离本文即视为缺陷,不提 PR、直接报 bug。

---

## 0. 不变量(Invariants)

以下任何版本迭代**禁止**违反:

1. 双容器、不嵌套;浮窗水平中心**必须**正对选中 App 图标,超界收进语境屏。
2. 全系统彩色仅两源:聚焦蓝 `--accent`、红绿灯三色。**禁止**引入第三种彩色。
3. **禁止**回弹/弹簧曲线;**禁止**任何动画超过 200ms。
4. 图标**必须**以原始 squircle alpha 渲染,**禁止** CSS 裁形;图标阴影**必须**用贴合轮廓的方式(drop-shadow / 图片层阴影),**禁止**矩形 box-shadow。
5. 窗口卡**禁止**出现标题栏带以外的文字、按钮、角标。
6. `prefers-reduced-motion` 下所有动效**必须**归零。

## 1. 度量系统

**一切尺寸是 4 的倍数。** 唯一例外:0.5px 发丝线与红绿灯(10px,系统规格)。

### 间距阶梯

| 阶梯 | 值 | 用途 |
|---|---|---|
| s1 | 4 | 微调,仅用于图标选中上浮等亚阶梯补偿 |
| s2 | 8 | 图标格间距、红绿灯间距 |
| s3 | 12 | 长条纵向内边距、浮窗内边距、卡间距、标题栏左缘 |
| s4 | 16 | 长条横向内边距、浮窗↔长条间距 |
| s5+ | 24/32 | 页面级留白,面板内不出现 |

规则:同层元素间距**必须**取自同一阶梯值(卡与卡、卡与边同为 s3——一个容器内只允许一阶节奏)。

### 圆角阶梯(同心规则:外角 = 内角 + 间距,取整到阶梯)

| 阶梯 | 值 | 用途 |
|---|---|---|
| r2 | 10 | 窗口卡(= macOS 窗口圆角实测) |
| r3 | 14 | 选中托底 |
| r4 | 20 | 两个面板容器 |
| — | 50% | 红绿灯 |

## 2. Token Reference

### 2.1 颜色(浅 / 深双值)

| Token | 浅色 | 深色 | 约束与理由 |
|---|---|---|---|
| `--accent` | `#007AFF` | `#0A84FF` | 系统聚焦环本色;深色提亮版沿用 Apple 自家换算,不另外发明 |
| 红绿灯 | `#FF5F57` `#FEBC2E` `#28C840` | 同左 | 系统规格,深浅不变 |
| `--txt-1` | `rgba(0,0,0,.85)` | `rgba(255,255,255,.87)` | 近似 labelColor;当前产品面无使用,保留位 |
| `--txt-2` | `rgba(0,0,0,.55)` | `rgba(255,255,255,.55)` | 窗口标题:辨识够用,存在感让位给截图 |
| `--plate` | `rgba(0,0,0,.06)` | `rgba(255,255,255,.10)` | 选中托底:刚好可见即停,深色系透明度约为浅色 1.7× |
| `--ko` | `rgba(250,250,252,.95)` | `rgba(22,23,27,.95)` | 聚焦环与截图间的剥离缝,取面板面色的近似色 |
| `--card-ring` | `rgba(0,0,0,.10)` | `rgba(255,255,255,.13)` | 未选卡 0.5px 纸边,防亮截图在亮玻璃上化开 |
| `--tb-tint` | `rgba(246,247,248,.5)` | `rgba(38,39,44,.5)` | 标题栏带:半透明磨砂,随截图内容变色 |
| `--tb-line` | `rgba(0,0,0,.06)` | `rgba(255,255,255,.08)` | 带下发丝:真实窗口的物证,非装饰 |

### 2.2 玻璃(单配方,两容器共用)

| 参数 | 浅色 | 深色 |
|---|---|---|
| tint | `rgba(250,250,252,.45)` | `rgba(28,29,33,.60)` |
| blur / saturate | 28px / 1.8 | 同左 |
| 顶部受光边 `--edge-hi` | 0.5px `rgba(255,255,255,.50)` | 0.5px `rgba(255,255,255,.12)` |
| 外轮廓 `--edge-ring` | 0.5px `rgba(0,0,0,.09)` | 0.5px `rgba(255,255,255,.11)` |

约束:tint 不透明度**禁止**超过 .65——玻璃的价值是透光,不是遮瑕。原生施工**必须**用 `NSVisualEffectView`(material `.popover`,state `.active`),本表数值仅作验收对照。

### 2.3 Elevation(阴影 = key 塑形层 + fill 锚定层)

层级即语义:**E3 浮窗 > E2 长条 > E1 卡片**。深色模式所有 α **必须** ×2.2(四舍五入)。

| 级 | 用途 | key(y / blur / α) | fill(y / blur / α) |
|---|---|---|---|
| E1 | 窗口卡静止 | 6 / 16 / .10 | 1 / 3 / .08 |
| E1-hover | 窗口卡悬停 | 8 / 20 / .13 | 2 / 4 / .09 |
| E1-sel | 窗口卡选中 | 10 / 26 / .15 | 2 / 6 / .10 |
| E2 | 图标长条 | 18 / 52 / .18 | 3 / 10 / .08 |
| E3 | 预览浮窗 | 26 / 72 / .22 | 5 / 14 / .10 |
| icon | 图标(贴合轮廓) | drop 4 / 10 / .18 | drop 1 / 2 / .12 |
| icon-sel | 选中图标 | drop 7 / 14 / .22 | drop 1.5 / 3 / .14 |

约束:**禁止**单层大阴影(糊成雾);**禁止**相邻层级交换(浮窗阴影弱于长条 = 层级反转)。

### 2.4 字阶

| 级 | 规格 | 用途 |
|---|---|---|
| t1 | 11px / 500 / 行高 1 | 窗口标题(带内居中,`max-width: 100% - 116px`,尾部 `…`) |

产品面板内只有这一个字号。出现第二个字号之前,先回来改本文档。

### 2.5 动效

| 动作 | 时长 | 曲线 | 位移 |
|---|---|---|---|
| 面板弹出 | 120ms | `cubic-bezier(.2,.8,.2,1)` | scale .96→1 + 透明 |
| 浮窗出现 | 120ms | 同上 | translateY -5→0 + 透明 |
| 卡片入场 | 160ms/张,相邻延迟 18ms | 同上 | translateY -6→0 + scale .97→1 + 透明 |
| 浮窗换组 | 本体静止,仅卡片重排 | — | 横滑已传达"换组",本体再动是重复播报 |
| 浮窗滑移 | 180ms | `cubic-bezier(.25,.8,.3,1)` | 仅 `left` |
| 状态切换 | 100ms | ease | 托底/环/阴影三属性**必须**同步 |

## 3. 组件解剖

### 3.1 Strip(图标长条,E2)

```
┌─ r20 ─────────────────────────────────┐
│  s3=12                                 │
│   ┌r14────┐  s2=8  ┌────┐              │
│ s4│ plate │········│cell│  …           │  cell = 80×80
│ 16│  icon │        │icon│              │  icon = 68×68(呼吸 6px)
│   └───────┘        └────┘              │
│  s3=12                                 │
└────────────────────────────────────────┘
```

- 选中托底:整格 `--plate`,r14,透明度 100ms ease;hover 仅到 45% 深度(主权在选中态)。
- 选中图标:`translateY(-1px)` + 阴影升 icon→icon-sel,与托底同帧。

### 3.2 Popover(预览浮窗,E3)

```
        ┌─ r20 ────────────── 中心正对选中图标 ─┐
        │ s3 ┌─ WindowCard ─┐ s3 ┌─ … ─┐ s3    │
        │    │              │    │     │       │
        └────┴──────────────┴────┴─────┴───────┘
                      s4=16(空气缝)
```

### 3.3 WindowCard(窗口卡,E1,r10)

```
┌ r10 ──────────────────────────┐
│ ● ● ●   <title 11/500 居中>    │ ← tbar 24px:磨砂带,左缘 s3,灯距 s2
├─ 0.5px --tb-line ─────────────┤
│                               │
│        截图 192px,等高          │ ← 宽随源图等比,禁止裁切定宽
│                               │
└───────────────────────────────┘
```

- 选中:`box-shadow` 双环 = 2px `--ko` + 2.5px `--accent`,同时阴影 E1→E1-sel。
- 红绿灯:10px 圆,带内垂直居中;内阴影三层(轮廓/受光/背光),禁止纯色平涂。
- 标题:超出 `…`;**禁止**换行、**禁止** tooltip 之外的补全手段。

| 组件 | default | hover | selected | 备注 |
|---|---|---|---|---|
| cell | — | plate 45% | plate 100% + icon 上浮 | hover 与 selected 叠加时按 selected |

## 5. 原生实现映射(SwiftUI / AppKit)

| Token | 原生 |
|---|---|
| 玻璃 | `NSVisualEffectView` `.popover` / `.active`,不手写底色 |
| E2/E3 | 两层 `NSShadow` 叠加或 `.shadow()` 两次;α 按深色 ×2.2 |
| icon 阴影 | 阴影打在 `NSImageView` 图片层(跟 alpha),不打在容器层 |
| 双环选中 | `StrokeBorder` 双层:内 2 `--ko`,外 2.5 `Color.accentColor` |
| tbar | 24pt 高 `.titlebar` material + 下缘 0.5pt `separatorColor` |
| 窗口标题 | `.system(size:11, weight:.medium)` + `.lineLimit(1).truncationMode(.tail)` + `.foregroundStyle(.secondary)` |
| 动效曲线 | `.timingCurve(0.2,0.8,0.2,1)` / `.timingCurve(0.25,0.8,0.3,1)`,禁止 spring |
