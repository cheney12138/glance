## 实验室的核心架构(与失败版的本质区别 ✗✗✗)
实验室原话:「高亮单元: 单一元素 translateX 滑移 —— 丝滑的核心」
「高亮做成单一元素，只动 transform:translateX，弹簧曲线滑移过去
 —— 不触发布局，全程走合成器，所以丝滑」

⇒ **滑动的不是一个真实图标条 ✗ 而是一个合成的"高亮单元"**:
  · 图标条装在 `#ring{max-width:min(82vw,900px); overflow:hidden; padding:12px}` 里 ✓
    (定宽容器 + 原生裁切 ✓ = 我们需要而没做对的"玻璃裁切" ✓)
  · 选中高亮 = 单个元素 translateX 滑移 ✓(弹簧曲线 ✓ 纯合成器 ✓ 不触发布局 ✓)
  · 溢出: `track.translateX(clamp(ringW-24-trackW, min(0,目标)))` ✓
    + `ring.classList.toggle('fade', overflow)` ✓(fade 类控制两端渐隐 ✓)
