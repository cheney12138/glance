# 私有 API 全局收口一处,失效即降级不崩溃

聚焦所需的私有调用(`_SLPSSetFrontProcessWithOptions`、 `SLPSPostEventRecordTo` 等)只允许出现在 `Focus/WindowFocuser` 一个文件内,工程其余部分只看见一个"聚焦这扇窗"的公开接口。任一私有调用失败时降级为 `NSRunningApplication.activate`——放弃单窗语义、回到级联拉起,但面板照旧工作;首次降级弹一次菜单栏警告,之后静默。

**为什么难撤销**:收口决定目录结构;降级路径决定模块接口要不要带"成败与否"的返回语义。

**为什么有争议**:私有化 API 项目常见的两手是"散布各处、哪里顺手哪里调"(alt-tab 早期)和"失效硬扛、崩给你看"。前者换 API 时伤筋动骨,后者把 macOS 升级日变成灾难日。我们选"圈禁 + 降级",用接口宽度换未来的可替换性。

**后果**:引入新的私有能力(未来的补焦、跨 Space)第一件事也是进这个文件,不在外面临时起意直调。
