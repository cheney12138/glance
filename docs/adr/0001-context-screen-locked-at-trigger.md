# 语境屏 = 触发快照,面板存活期间锁定

面板的"当前屏"在触发瞬间由鼠标光标位置快照决定,之后整个导航态里光标去哪都不再改变它。唯一的例外:光标移入展开层缩略卡仍可改"选中",但绝不改"语境屏"。

**为什么难撤销**:语境是枚举过滤、选中仲裁、面板落点三个模块的共同上游,改成"实时跟鼠标"等于换掉产品的时空观。

**为什么不跟键盘焦点**:用户的工作模型是"鼠标滑到哪块屏=想操作哪块屏"(触摸板/鼠标是他最高频的输入),键盘焦点会撒谎——他就是被"焦点在 A 屏、人想操作 B 屏"的错位咬到才立的这个项。

**为什么不实时跟鼠标**:按住 ⌥ 时手一抖滑过另一屏,候选列表当场换掉、松开焦点跳到对面——等于亲手复刻 AltTab 最令人恼的上下文漂移。锁死快照是这个产品对所有"漂移"的总回答:触发即定场,活着期间世界不变。

**后果**:跨屏使用想切另一屏?放弃(Esc)→ 鼠标过去 → 重新触发。这是设计内的动作,不是缺陷。
