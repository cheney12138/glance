## 二、目录分类说明

- **`docs/adr/`**：架构与行为硬边界决策（`0001`–`0018`），提新方案前先核对是否触及既有硬边界。
- **`docs/patterns/`**：可复用的交互/系统能力工程模式沉淀：
  - [拖拽源浮窗.md](patterns/拖拽源浮窗.md)（贴身跟随系统设置窗的 Finder 同款 App 拖拽浮层模式）
- **`docs/archive/`**：已结案的一次性阶段排查与验收档案（历史留痕，平时无需翻阅）：
  - `白光排查记录.md` · `排查-托盘卡片要点两次.md` · `掉帧排查-现状.md` · `验收-未启动环黑白名单.md` · `托盘与环-两条独立的比例.md`
- **保留在 `docs/` 顶层的源码引用专题**：[架构-领域与基础设施.md](架构-领域与基础设施.md)、[重构清单.md](重构清单.md)、[量尺代价表.md](量尺代价表.md)、[手势-输入源-IOHID-可行性.md](手势-输入源-IOHID-可行性.md)（已被源码注释或 ADR 直接引用，保持原路径不变）。
- **本地资产（`.gitignore`，不进远端）**：
  - `../design/`：HTML 交互实验台、Icon 裁切脚本、`v4/` 设计稿与规范（源码注释仍有路径引用，仅保留在本机参照）。
  - `../AGENTS.md` / `../CONTEXT.md`：本地编码协作规矩与领域词表。
