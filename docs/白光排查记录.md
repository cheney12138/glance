# 「一道白光」排查记录（2026-09-17）

> 现象：**进程起来后的第一次**唤起面板，一排 App 图标上方闪过**一条亮带**；第二次起就没有。
> 它**不是卡顿**（`[帧] … 长帧 0(0%)`），所以帧率探针天生抓不到 —— 这是它在仓库里躲了很久的原因。

## 一、已经由**数据**定死的事实（不要再重复验证）

| 事实 | 怎么得到的 |
|---|---|
| **发布版 `v0.1.2` 不闪** | 用户实机，`~/Applications/Glance.app`（Homebrew 装的），`ps` 验明正身 |
| **`811a26f` 闪** | 用户实机（把工作区退回 `811a26f` 后复现） |
| **`811a26f~1`(`e63ff40`) 单独编不过** | `git switch --detach e63ff40` ⇒ `coldStartSweep` 与 `trayLayout(count:)` 都缺 |
| 动态色不是元凶 | 探针量出第一次/第二次**完全相同**：`lip=1.00/1.00/1.00@0.10`、`top=0.00@0.00`、`inner=0.00@0.06`，且都是 `@light` |
| `glassLip`（软的受光唇）**根本没画** | `PanelEdgeStyle.drawsEdge = false`（编译期常量） |

实际把**好几个改动切成了两半**（调用先提交、实现后提交）⇒ **按提交往回二分走不通**（中间提交编不过）。
